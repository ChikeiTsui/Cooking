# 调料放入顺序

## 盐

1. 肉下锅变色后放，盐渗进肉里，入味不柴
2. 青菜出锅前放
3. 煲汤出锅前15-10分钟放

## 酱油

1. 油热沿着锅边放生抽，不要出锅前放
2. 老抽中途放上色
   
## 白糖

1. 早放，提鲜
   
## 耗油、鸡精、味精

1. 关火前、出锅前放一点，利用余温翻炒均匀就可以了

## 白胡椒粉

1. 肉汤出锅前放

## 花椒粉

1. 出锅前、盛盘后放
   
## 水淀粉

1. 出锅前淋，边搅拌边淋

## 葱姜蒜

1. 先放姜再放蒜最后出锅前放葱，温油下

## 醋

1. 油热放 去酸留香（烹醋）
2. 出锅前放，留酸爽和清新（点醋）

# 油温控制

## 热锅凉油

操作：锅烧热烧干水分，倒入少许底油润锅，加热至微微冒烟，最后倒入常温凉油

适合菜品：煎鱼、煎蛋、炒肉片肉类，煸葱姜蒜香料

优点：超强不粘、不易粘锅，适配日常绝大部分家常菜。

## 热锅热油

操作：锅烧热烧干水分，倒入食用油，加热至微微冒烟，油温拉满，全程大火猛火快速翻炒。

适合菜品：清炒绿叶青菜、爆炒牛肉、炒猪肝、腰花等嫩肉食材。

优点：高温快速锁熟，食材不易出水软烂，炒出来的菜干爽入味、脆嫩爽口，口感绝佳。

## 冷锅冷油

操作：不开火，先往冷锅里倒入食用油，在开火加热，直接下食材。

适合菜品：炸花生米，煸花椒、干辣椒等易糊香料，滑蛋也适合。

优点：升温缓慢，避免食材瞬间高温焦糊，口感更软糯鲜香。

# 香辣啤酒炒螺蛳

## 一、食材

螺蛳2斤（加入少量食用油，2勺食用盐吐沙）

## 二、配料

生姜4片、大蒜7-8瓣（切片）、小米椒2-3根（切圈）、干辣椒适量（切段）、花椒一小把、生抽1汤勺、耗油1勺、盐1勺、白糖2勺、白胡椒粉少许，鸡精少许、陈醋1勺、啤酒500ml、菜籽油+少许猪油混合油、八角、香叶、桂皮

### 三、烹饪

1. 处理好的螺蛳冷水下锅，加入姜片，水开后再煮2分钟，捞出用温水洗净沥干。
2. 热水下混合油，油热后转小火放入姜片、蒜片、小米椒圈、干辣椒、花椒炒出香味。
3. 转大火，倒入螺蛳快速翻炒均匀，沿锅边倒入一勺啤酒和生抽，大火炒出香气。
4. 倒入剩余啤酒，以没过螺蛳为宜，加入盐、白糖、白胡椒粉、鸡精调味，大火煮5-6分钟。
5. 煮到一半加入适量八角、香叶、桂皮。
6. 汤汁收至浓稠时，出锅前沿锅边淋入一勺陈醋，快速翻炒几下出锅。
   
# 爆炒花甲

## 一、食材

花甲1斤（加入少量食用油，2勺食用盐吐沙）

③ 温水+盐+摇晃/搅拌法（⭐快速推荐）

做法：

1. 盆中放 35～40℃ 温水（手感温热不烫），加一勺盐搅匀。

2. 放入花甲，上手或盖盖子用力摇晃盆子 1～2 分钟，或用手轻轻顺时针搅拌几次。

3. 静置 20～30 分钟，看到盆底有沙析出即可捞出冲洗

## 二、配料

青辣椒1个、小米椒1个、姜两片（切条）、蒜3瓣（切片）、料汁（生抽2勺、耗油1勺、料酒1勺、白糖半勺、淀粉1勺、清水5勺）搅拌均匀

### 三、烹饪

1. 锅内放入少量清水和花甲，水开煮2分钟捞出控干水分。
2. 锅内放入少许油爆香姜蒜。
3. 放入花甲，翻炒均匀。
4. 放入料汁，翻炒均匀。
5. 倒入青辣椒小米椒翻炒出锅。

# 青椒炒肉

## 一、食材

五花肉2块（切片）

## 二、配料

生姜2片、大蒜5瓣（切片）、青椒4-5根（切斜圈）、生抽1勺、耗油1勺、老抽半勺、料酒1勺

### 三、烹饪

1. 起锅烧热，锅内不加油干煸辣椒变软捞出。
2. 锅内加入少量菜籽油，放入五花肉炒熟。
3. 加入生姜大蒜爆香。
4. 加入生抽1勺、耗油1勺、老抽半勺、料酒1勺和适量水翻炒均匀。
5. 加入青椒大火翻炒1-2分钟出锅。

# 炖排骨

## 一、食材

排骨（焯好）
姜 4–5片、葱 1根（挽结）
料酒 1勺
盐 
可选提香：枸杞一小撮、红枣2–3颗、玉米段/藕片/山药段

用量参考（4人份）：排骨 500–800g
1. 泡血水（10–20分钟）  
冷水浸泡，加 1勺盐和1勺面粉轻轻抓洗，水变红就换水，直到水变清(盐/面粉吸附效果更好，比“光泡水”明显更不腥)
1. 焯水（必须冷水下锅）  
排骨捞出 冷水下锅 加姜片3–4片 + 葱段1根 + 料酒1勺​  
开火煮沸 → 浮沫大量冒出 → 撇净浮沫（很关键）  
再煮 2–3分钟​ → 捞出  
用温水冲洗表面浮渣（尽量别用滚烫开水猛冲，肉容易发紧）  

### 三、烹饪

锅里这样放（顺序影响香气和肉嫩度）
1. 锅里放 排骨 + 姜葱 + 料酒​
倒入 热水（别用冷水或开水），水量 没过排骨2–3cm​,先大火烧开​ → 撇最后一丢浮沫 → 立刻转 最小火​
2. 盖盖炖约 40–60分钟​
3. 最后10分钟：放盐调味（一般 1小勺≈3g​ 起步，边喝汤边补盐更稳）
4. 出锅前撒 白胡椒粉一点点 + 葱花/香菜


# 土豆炖排骨

## 一、食材

排骨500克、土豆2个  

## 二、配料

香叶2片、八角3个、桂皮1块、冰糖6粒、香葱2根、姜片6片、大葱片6片  

## 三、烹饪

**排骨处理** 

1. 泡血水（10–20分钟）  
冷水浸泡，加 1勺盐和1勺面粉轻轻抓洗，水变红就换水，直到水变清(盐/面粉吸附效果更好，比“光泡水”明显更不腥)  
2. 焯水（必须冷水下锅）  
排骨捞出 冷水下锅 加姜片3–4片 + 葱段1根 + 料酒1勺​  
开火煮沸 → 浮沫大量冒出 → 撇净浮沫（很关键）  
再煮 2–3分钟​ → 捞出  
用温水冲洗表面浮渣（尽量别用滚烫开水猛冲，肉容易发紧）  

1. 小火放适量油和冰糖，炒至冰糖完全融化，下排骨翻炒均匀  
2. 放入葱姜片、香叶、八角、桂皮炒香  
3. 加入1勺生抽、1勺老抽、1勺耗油，翻炒均匀  
4. 加入没过排骨的热水，水开转小火、盖盖煮25分钟  
5. 加入适量盐、土豆，继续炖15分钟  
6. 炖至土豆熟透，大火收汁，放入葱花  

# 河南焖面  

## 一、食材  

五花肉（薄片）、豆芽、豆角（手掰）、芹菜（根茎切段）、面条（薄、窄、湿、鲜）

## 二、配料  

大葱（斜段）、姜（8小片）、蒜（蒜蓉，蒜瓣）、八角（2颗）、干辣椒段、花雕酒/料酒（1勺半）、开水、盐（2勺）、味精（2勺）、耗油（1勺半）、生抽（2勺）、老抽（3勺+）

## 三、烹饪

1. 热锅凉油，小火煸香五花肉，打卷拨到旁边
2. 下葱姜炒香，下辣椒段和八角2颗炒香，加入生抽2勺炒出酱香味
3. 下芹菜豆角黄豆芽，翻炒后锅边淋入花雕酒（料酒），加入开水至与菜齐平
4. 加入盐2勺、味精2勺、耗油1勺半、老抽3勺+（颜色得深）
5. 锅开倒出三分之二汤汁，面条抖散平铺，盖上锅盖，中火焖3分钟
6. 把焖好的面条翻面，均匀淋上一半汤汁，面抖散，盖上锅盖，中火焖3分钟
7. 将剩余汤汁均匀浇到面上，炒拌均匀，盖上锅盖，中火焖3分钟
8. 撒上蒜蓉，抄底将面和菜拌匀

# 炖排骨汤

## 一、食材

新鲜排骨（非冷冻）

## 二、配料  

八角（1颗）、桂皮（1片）、香叶（1叶）、花椒、大葱（段）、姜（片）、枸杞、小葱（圈）  

胡萝卜（片）、玉米（块）、冬瓜（片）  

## 三、处理  

1. 排骨清水浸泡30min，血水逼出，清洗2，3遍，去除多余油脂。  
2. 薄油滑锅，排骨下锅收紧表皮，下八角、桂皮、香叶、花椒、大葱、姜煸一会后取出排骨。  

## 四、烹饪  

1. 不加盖，小火慢炖1h，将上面多余油脂浮沫撇一撇  
2. 加入配菜一起炖  
3. 加入盐调味  
4. 加入枸杞  
5. 小葱打底，盛肉出汤
